# 脚本生成数据和资源
支持通过python脚本生成数据和资源

## 角色
通过继承`Persona`类，来创建一个角色

```python
class PersonaID(Persona):
    name = "persona_name"
    color = "#ffffff"
```

## 场景
通过继承`Scene`类，来创建一个场景

```python
class SceneID(Scene):
    name = "scene_name"
```

## 对话
通过继承`Dialogue`类，来创建一个对话

```python
class DialogueID(Dialogue):
    scene = SceneID

    def flow(self):
        a = self.persona(PersonaID)
        a.say("start")
```
