# 模块的结构
描述了引擎加载模块的结构，模块可以加载自己的gui、角色、场景、剧本、效果...

每一个模块都必须是一个python包（可以是zip压缩文件），内容如下：
- 模块根
    - info.json 模块信息
    - resources 资源
        - images 图像资源
        - audios 音频资源
        - animations 动画资源
        - languages 语言资源
    - data 数据
        - personas 角色数据
        - scenes 场景数据
        - dialogues 对话数据
        - ui 界面数据
    - scripts 脚本
        - flow 流程控制
        - effectors 效果器
        - ui 界面脚本
